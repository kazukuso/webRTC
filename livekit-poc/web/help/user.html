言語を選んで「通訳を呼ぶ」だけで、対応可能な通訳者にビデオ通話でつながります。

通話の呼び出し

  1. ご希望の言語を選びます。
  2. （パターンB・任意）「現在地を送信する」に同意すると市区町村を記録します。
  3. 通訳を呼ぶ を押します。「順番をお待ちください（○番目）」と表示されます。
  4. 担当が空くと自動的に通話が始まります。

通話中の操作

  • マイク オフ / カメラ オフ：音声・映像の一時停止。
  • 退室：通話を終了して受付画面に戻ります。

カメラの切り替え（スマホ・タブレット）

前面（インカメラ）と背面（アウトカメラ）を切り替えられます。

  • 通話画面の カメラ切替 を押すたびに、イン⇔アウトが切り替わります。
  • このボタンはカメラが2つ以上ある端末（スマホ/タブレット）でのみ表示されます。PCなど1つの端末では表示されません。

背景のぼかし・差し替え

自分の映像の背景をぼかしたり、画像に差し替えられます。

  • 通話画面の「背景」から なし / ぼかし / 背景1 / 背景2 を選びます。
  • 初回は準備に数秒かかります。対応していない端末ではボタンは出ません。
背景処理は端末に負荷がかかります。動作が重い・発熱する場合は「なし」に戻してください。

お支払いが必要な端末の場合（課金）

課金対象の受付端末では、通話が有料（従量課金）になります。初回にカードを登録すると、以降は自動で決済されます。

カード登録（初回のみ）

  1. 受付画面の カード登録 を押します。
  2. 安全な入力画面（Stripe）でカード番号を入力します（番号はStripe側で保管されます）。
  3. 登録後は「お支払いカード: visa ****4242（登録済み）」と表示されます。

料金と延長

  • 接続時に基本料（初期100円・最初の5分）が決済され通話開始。
  • 通話画面に残り時間・現在の料金・延長する（+¥100）が表示されます。
  • 延長したい時はボタンを押すと5分延長（追加料金）。押さずに時間を過ぎると自動終了します。
決済に失敗すると通話は接続されません（または延長されません）。カードは受付画面の「カード変更」から再登録できます。

困ったとき

症状対処
カメラが使えない/映像が出ないブラウザのカメラ許可を確認（許可ダイアログで「許可」）。
つながらない対応言語の通訳者が空くまでお待ちください。時間がかかる場合は担当へ。
背景/切替が出ない非対応の端末・ブラウザの可能性。最新のChrome/Edgeを推奨。
