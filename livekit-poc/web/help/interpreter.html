「応対可」にすると自動で着信します。着信すると通話画面に切り替わります。

基本の流れ

  1. 応対可にする を押して受付可能にする（担当言語の待機数が表示）。
  2. 呼び出しがあると自動で着信し、ビデオ通話に切り替わります。
  3. 通話中は マイク オフ / カメラ オフ で切替。
  4. 終了は 通話終了。席を外す時は 離席。

録画

通話中に ● 録画開始 / ■ 録画停止 で録画できます（管理の通話履歴に録画有無が残ります）。

背景のぼかし・差し替え

  • 通話画面の「背景」から なし / ぼかし / 背景1 / 背景2。
  • 初回は準備に数秒。非対応端末では表示されません。
背景処理は負荷が高めです。重い場合は「なし」に戻してください。
担当できる言語は管理者が各アカウントに設定します（例：英語通訳者=en）。
