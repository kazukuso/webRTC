全体の設定・監視・履歴・料金/売上・アカウント管理を行います。上部タブで切り替えます。

タブ別の機能

タブ内容
リアルタイム監視言語別の待機数・対応中の通話・在席スタッフを常時表示（3秒毎更新）。
通話履歴言語/状態で絞り込み、地図リンク、CSVダウンロード。
稼働レポート総受付・応答・放棄・応答率・平均待ち/通話・録画数。
マスタ管理対応言語の追加/有効化、受付端末（モード/接続方式）。
ユーザー管理各ロールのアカウント作成・編集（課金要否もここ）。
課金・売上料金設定と売上/決済履歴。
ログログイン・割当・課金などの操作イベント。

ユーザー作成・課金要否

  1. 「ユーザー管理」タブを開く。
  2. ユーザー名・表示名・パスワード・ロールを入力。
  3. ロールが「利用者」のとき、モード(A/B)と課金（課金なし/課金あり）、方式（会員=保存カード/ゲスト=都度）を選ぶ。
  4. 追加/更新で保存。編集時はパスワード空欄で変更なし。
「課金あり」の利用者アカウントの通話だけが従量課金の対象です。Stripeキー未設定時は「金額の記録のみ」で実決済は行われません。

課金・売上（料金設定）

「課金・売上」タブで、基本料・基本ぶんの分数・延長単位・延長料・猶予を変更できます（初期: 基本100円/5分、延長100円/5分、猶予15秒）。売上サマリと決済履歴も確認できます。

背景・カメラ切替について

通話画面の背景ぼかし/差し替えは全ロールで利用可。カメラ切替（イン/アウト）は利用者画面のみで、2カメラ端末で表示されます。いずれも端末性能に依存します。
